前端组件设计

React 组件树与交互逻辑

组件树结构
App
├── DevicePanel （左栏）
│   ├── DeviceList — 设备卡片，连接状态徽标
│   └── AppList — 已安装 App，含图标缓存
├── FileBrowser （右侧主区）
│   ├── BreadcrumbBar — 路径导航，可点击跳转
│   ├── Toolbar — 视图切换 / 导入导出 / 多选操作
│   ├── FileGrid — 网格视图（图标 + 文件名）
│   └── FileList — 列表视图（名称/大小/时间）
└── TransferPanel （底部浮层）
     └── TransferItem — 进度条 + 取消按钮
🖱️ 拖拽交互
从设备拖出到 Mac
拖拽文件 → 触发 Tauri startDrag API → 系统接管拖拽 → 放到 Finder/桌面自动下载
从 Mac 拖入设备
Mac 文件拖入 FileBrowser → ondrop 捕获本地路径 → 调用 Rust upload_files → 加入 transfer_queue
☑️ 多选操作
• Cmd+点击 逐个选中  |  Shift+点击 范围选中  |  Cmd+A 全选
• 选中后 Toolbar 显示批量操作按钮：导出、删除
• 拖拽选中项整体移动（多文件一次性传输）
📦 状态管理
使用 Zustand（轻量）管理全局状态：设备列表、当前选中设备/App、当前路径、文件列表缓存、传输队列。Tauri Event 监听设备变化和传输进度，自动更新 store。
