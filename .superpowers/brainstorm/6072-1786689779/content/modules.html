核心模块设计

各模块职责与接口划分

📱 ios_client — iOS 设备通信
职责
  • 检测 USB/WiFi 连接的 iOS 设备
  • 列出安装的 App（bundle id + 名称）
  • 通过 AFC 协议访问 Documents / Cache / Library
  • 上传 / 下载 / 删除文件
调用工具
idevice_id -l
ideviceinstaller -l
ifuse --container <bundle_id>
cp / rm via mounted path
🤖 android_client — Android 设备通信
职责
  • 检测 adb 连接设备
  • 列出已安装 App（package list）
  • 访问 /data/data/<pkg> (run-as) + /sdcard
  • adb pull / push / ls / rm
调用工具
adb devices
adb shell pm list packages
adb shell ls -la <path>
adb pull / adb push
📂 file_ops
  • 列目录（返回文件元信息）
  • 读取单文件内容
  • 创建 / 删除 / 重命名
  • 批量操作（多文件打包）
⏳ transfer_queue
  • 任务队列（并发控制）
  • 进度事件推送（Tauri emit）
  • 支持暂停 / 取消
  • 错误重试
🔌 device_manager — 热插拔检测
轮询 adb devices 和 idevice_id -l（每 2 秒），设备连接/断开时通过 Tauri Event 推送前端更新设备列表。
