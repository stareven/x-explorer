系统架构概览

x-explorer 整体模块关系

React 前端 (TypeScript)
DevicePanel — 设备 + App 列表
FileBrowser — 文件树浏览
FileGrid/List — 双视图切换
Toolbar — 导入/导出/多选操作
DragDrop — 拖拽层（双向）
⇄
Tauri IPC
Rust 后端 (Tauri Commands)
device_manager — 设备检测与连接
ios_client — AFC 协议封装
android_client — adb 命令封装
file_ops — 读/写/列目录/传输
transfer_queue — 传输队列/进度
⇄
subprocess
内置二进制
adb (Android)
ideviceinstaller
ifuse / idevice CLI
连接设备
📱 iOS (USB/WiFi)
🤖 Android (ADB)
数据流： 前端通过 Tauri invoke() 调用 Rust Command → Rust 调用内置 adb/idevice 工具 → 解析输出 → 返回结构化数据给前端渲染
