# Device List Name and ID Display Design

**日期：** 2026-08-17
**状态：** 已确认

---

## 概述

设备面板中的每个设备项将以设备名称作为主标题，以设备 `id` 作为副标题显示。这样既保留当前的主要识别信息，也让同名设备更容易区分。

---

## 范围

本次变更影响设备名称采集和前端设备列表渲染：

- iOS 设备名称从 `ideviceinfo` 输出中的 `DeviceName` 读取
- Android 设备名称优先从 `adb devices -l` 输出中的 `model:` 读取；如果长列表里没有型号，则对已连接设备再用 `adb -s <id> shell getprop ro.product.model` 兜底
- 设备名称继续作为第一视觉层级
- 设备 `id` 作为更小、更浅的辅助文本显示
- 设备选择、平台图标、状态徽标和交互保持不变

不修改设备数据结构。名称不可用时继续回退显示设备 `id`。

---

## 设计

设备列表项继续使用现有按钮结构和点击行为，只把文本区域从单行改成两行：

- 第一行：`device.name`
- 第二行：`device.id`

副标题使用较小字号和较低对比度，必要时允许截断，避免长 `id` 破坏列表布局。按钮宽度、状态点、选中态和悬停态保持原样。

---

## 验证

验证重点只有两项：

- 名称仍然作为主文本显示
- `id` 作为副文本可见

对应的组件测试会更新为断言这两层文本都存在，并继续覆盖点击选中和无信任状态徽标的现有行为。
